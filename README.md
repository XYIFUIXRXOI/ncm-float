# NCMFloat · 网易云音乐悬浮窗

一个 **Material 3（Google 设计语言）** 风格的网易云音乐**第三方悬浮窗控制器**：无需 root、无需无障碍权限，通过系统媒体按键直接控制播放。

![App 图标](res/drawable/ic_launcher.png)

## 功能特性

- 桌面上常驻一个悬浮球（浅蓝色调圆球 + ♪），可随意拖动位置
- 点击悬浮球 → 在球**下方**展开竖向控制面板（淡入 + 上滑 + 缩放过渡动画），悬浮球保持原位不动
- 三个 Material 3 圆形按钮：
  - 上一首（色调按钮：浅蓝底 + 谷歌蓝图标）
  - 播放 / 暂停（主按钮：主题蓝底 + 白图标，随播放状态自动切换）
  - 下一首（色调按钮）
- 无任何黑色投影（elevation），纯 Material 3 设计语言
- 长按悬浮球 2 秒关闭悬浮窗；通知栏常驻「停止」入口

## 安装步骤

1. 安装 `dist/NCMFloat-v1.3.apk`（允许「未知来源」）
2. 首次打开 App → 授予「悬浮窗权限」（显示在其他应用上层）
3. Android 13+ 还需授予「通知权限」（用于常驻通知）
4. 返回桌面即可看到悬浮球，在网易云音乐播放时点击即可控制

## 使用说明

- 控制原理：向系统发送媒体按键（上一首 / 播放暂停 / 下一首），控制当前活跃的媒体会话，网易云音乐播放中即可直接控制
- 播放/暂停图标根据系统「是否有音乐正在播放」自动切换；若其他音乐 App 同时在播，状态可能不完全精确，属正常现象


- 仅用于学习交流；非网易官方应用，与网易云音乐无任何关联
